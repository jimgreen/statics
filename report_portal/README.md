# Report Portal

这是一个独立的轻量 Web 报表门户，用于把已下载的报表项目先串成可运行的“定义 → 运行 → 查询 → 导出”闭环。

## 功能

- Web 前端定义报表：名称、说明、只读 SQL、表格/折线/柱状/饼图、横轴/数值列、输出格式。
- 网格版式设计器：编辑单元格内容，Shift 选择区域，复制/粘贴、合并/拆分、字号、粗体/斜体、文字色、填充色、对齐和线型；版式保存在报表定义中，并输出到 HTML 和 Excel 的“版式”工作表。
- 单元格/图元独立数据源：每个网格元素可单独选择静态内容、主查询字段、独立只读 SQL 或统计公式；元素类型支持文本、数值/字段、动态表格和折线/柱状/饼图。动态表格不预设行数，按独立 SQL 返回结果在指定单元格展开。
- 定义效率：SQL 只读预览（支持行数上限和耗时显示）、报表一键复制、网格行列数调整、未保存修改提示，以及 Ctrl+S 保存和 Ctrl+Enter 运行快捷键。
- 参数化报表：可定义文本、日期、数字和下拉参数，在 SQL 中使用 SQLite 命名参数（如 `:start_date`）；人工运行填写参数，定时运行使用默认值，实际参数会保存到运行历史和导出文件中。
- 定义迁移：支持将当前报表定义导出为 `.report.json`，在另一套门户中导入复用；导入后的自动调度默认关闭，确认数据源后再启用。
- Excel 风格统计公式：每行一条“名称 = 公式”，支持 `MAX`、`MIN`、`AVERAGE`、`SUM`、`COUNT` 和按横轴梯形积分的 `INTEGRAL(数值列, 时间列)`；也支持 `B2:B100` 单元格范围。
- 后端使用 SQLite 保存报表定义和运行历史；默认数据库文件为 `D:\codex\sqldb\realtime\statics\report.db`，外部默认数据库不会创建演示数据。
- 异步执行报表 SQL，生成 HTML、CSV、带原生图表的 XLSX，以及包含标题、统计值、版式和明细表的 Word（DOCX）文档。
- 自动计划：支持仅手动、按间隔和每日指定时间；每日计划可选择 IANA 时区，并显示下次执行时间。
- 保存并运行：自动保存当前修改后人工执行，保留本次参数；保存失败时不会继续执行。后台刷新不会覆盖正在编辑的草稿。
- 报表按名称/说明搜索，执行历史按名称/参数、状态、人工/定时来源筛选；保留运行时的计划和参数，可预览数据并下载当次实际生成的文件。
- 结果页显示统计卡片，HTML 报表带统计值表，Excel 额外生成“统计值”工作表。
- `REPORT_DB_PATH` 环境变量可指定已有 SQLite 数据库，例如：

  ```powershell
  $env:REPORT_DB_PATH='D:\data\business.db'
  python .\report_portal\app.py
  ```

  如果只需要更换默认数据库目录，可设置 `REPORT_DB_DIR`；数据库文件名固定为 `report.db`：

  ```powershell
  $env:REPORT_DB_DIR='D:\data\reports'
  python .\report_portal\app.py
  ```

## 启动

在 `D:\codex\statics` 下执行：

```powershell
python -m pip install -r .\report_portal\requirements.txt
python .\report_portal\app.py
```

打开 <http://127.0.0.1:8766>。如果需要 Excel 导出，请确保环境安装了 `openpyxl`；当前开发环境已具备该依赖。

## 调度与运行规则

- **仅手动**：保存后点击“保存并运行”，也可按 Ctrl+Enter；人工运行始终可用。
- **按间隔**：间隔至少为 1 分钟，从启用或修改计划时开始计时，自动执行保持原定节拍。
- **每天指定时间**：例如每天 `08:30`、时区 `Asia/Shanghai`。默认时区为 `Pacific/Auckland`，可通过 `REPORT_TIMEZONE` 环境变量修改；Windows 环境的时区数据由 `tzdata` 依赖提供。页面上的下次时间和历史时间按浏览器本地时区显示。
- 定时任务使用参数默认值，启用前会校验必填参数。人工任务使用本次输入的参数；人工运行、修改说明或版式不会推迟原定计划。
- 暂停/停止仅影响自动调度，已开始的任务继续执行；同一报表不并发执行。服务进程需要保持运行才能按时生成报表。
- 暂停或停机期间错过的多次执行合并为一次，恢复后执行一次并推进到未来时间；失败会记入历史并等待下一次计划，不会每秒重复触发。
- 夏令时前跳导致指定时间不存在时，按跳过的时长顺延；回拨产生两个相同本地时间时，只在第一次执行。
- 复制和导入保留计划设置，但默认关闭自动调度。旧版间隔计划会自动迁移，旧运行历史标注为“旧版记录”。

输出默认保存在 `report_portal/output`，可以用 `REPORT_OUTPUT_DIR` 指定独立目录。每次运行使用独立子目录，切换数据库也不会因为运行编号重复而覆盖旧文件。

## 回归检查

在项目根目录执行，使用独立临时数据库和输出目录，不修改生产报表：

```powershell
python -m unittest discover -s report_portal/tests -v
node --check report_portal/static/app.js
```

## 后续接入商用数据库

当前门户直接针对 SQLite，目的是先把 Web 流程和权限边界跑通。若要接入 SQL Server、Oracle、MySQL 或 PostgreSQL，可将 `connection()` 抽象为 SQLAlchemy engine，并为每个数据源保存只读连接配置；前端的报表定义、调度、结果和下载接口无需改变。
